UI Kit — готовые компоненты ​

Настройки самого конструктора описаны на странице UI Kit, а классы, которые он генерирует, — в контракте классов.

Здесь собраны готовые компоненты для каталога, разметка которых рассчитана на стили, генерируемые конструктором UI Kit (var_control). Вы настраиваете внешний вид один раз в конструкторе (цветовые роли, типы заливок, размеры, иконки), а компоненты выводят разметку под этот контракт — не нужно вручную собирать классы вроде btn--exdoc btn--accent btn--solid и слоты иконок.

Каждый компонент вызывается как обычный компонент exDoc:

twig
{{ ex.component('<hashtag>', { …параметры… }) }}

Компоненты ​

КомпонентВызовОписание
Кнопкаex.component('button', {…})Кнопка или ссылка с ролью, заливкой, размером и иконками.

Список будет пополняться другими UI-элементами (бейджи, поля, карточки и т.д.).

Стили содержимого ​

Не всё в UI Kit оформлено компонентом. Типографика стилизует вашу собственную разметку — заголовки, абзацы, списки и цитаты внутри области контента: вызывать нечего, достаточно пометить контейнер классом.

Как это устроено ​

  • Стили приходят из конструктора UI Kit: цветовые роли, типы заливок (solid/outline/soft/ghost), размеры, состояния. Генератор эмитит их как классы-модификаторы на маркере (btn--exdoc и т.п.).
  • Компонент даёт только разметку под этот контракт классов и подставляет модификаторы из переданных параметров. Никакой собственной раскраски у компонента нет — он полностью опирается на сгенерированные стили.
  • Меняя настройки в конструкторе, вы меняете вид всех кнопок сразу, не трогая шаблоны.
