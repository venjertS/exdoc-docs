UI Kit — Типографика ​

Часть раздела UI Kit.

Типографика — единственный элемент UI Kit, у которого нет своего компонента: она стилизует вашу собственную разметку. Описания товаров, статьи, тексты блоков и документов пишутся обычными тегами <h2>, <p>, <ul>, а вид им задаёт конструктор.

Настраивается в Быстрых настройках → UI Kit → Типографика.

Область действия ​

Стили не применяются ко всей странице — только внутри контейнера с классом-маркером:

html
<div class="prose--exdoc">
  <h2>Заголовок раздела</h2>
  <p>Обычный абзац со <a href="#">ссылкой</a>.</p>
</div>

Это сделано намеренно: шапка, меню, карточки товаров и кнопки не должны получать книжные отступы и размеры вместе с текстом статьи.

Если в теме уже есть контейнер контента (content, article, entry — что угодно), впишите его класс в поле рядом с маркером. Тогда стили начнут действовать и по нему, и переписывать шаблоны не придётся.

Когда стили мешают — .not-prose ​

Внутри статьи попадаются вставки, которым типографика не нужна: галерея, форма, готовый компонент UI Kit, чужой виджет. Пометьте такую вставку классом-исключением — стили не тронут ни её, ни вложенное в неё:

html
<div class="prose--exdoc">
  <p>Обычный текст статьи.</p>

  <div class="not-prose">
    <!-- сюда типографика не лезет -->
  </div>
</div>

Имя класса настраивается: если в проекте уже принято другое, впишите своё.

Заголовки вне текста ​

Заголовками подписывают не только статьи: карточки товаров, секции лендинга, блоки, виджеты. Тумблер «Применять на всём сайте, а не только в тексте» в секции «Заголовки» выносит лестницу за пределы прозы — настроенные h1–h6 начинают действовать везде.

Наружу уходит только вид заголовка — шрифт, размер, вес, цвет, регистр, трекинг. Отступы остаются в тексте: полуторакегельный отступ сверху — это ритм между абзацами статьи, а на заголовке карточки он лишний.

html
<!-- вид заголовка тот же, что в статье; отступов прозы нет -->
<div class="card">
  <h3>Название товара</h3>
</div>

Это единственный способ получить единые заголовки на сайте: вписать класс карточки в поле скоупа нельзя — вместе с заголовками к ней приедут ширина строки (схлопнет вёрстку), отступы абзацев и стили списков.

Что важно знать:

  • Тумблер выключен по умолчанию: включённый он меняет вид заголовков по всему сайту, и делать это без спроса модуль не должен.
  • Класс-исключение работает и снаружи: вставка с .not-prose остаётся нетронутой.
  • Правила намеренно слабые — вес такой же, как у обычного h1 в стилях темы. Ваш собственный .card h2 перебивает лестницу без всяких ухищрений, и это задумано: кто пишет такое правило, тот именно этого и хочет. Если же тему перебить не удаётся — подключите стиль exDoc после её стилей.
  • Отдельной лестницы для «блочных» заголовков нет и не будет: два набора размеров заголовков на сайте — почти всегда ошибка проектирования.

Классы-двойники заголовков ​

У каждого уровня есть класс с тем же именем: .h1 … .h6. Он даёт ровно тот же вид, что соответствующий тег.

Нужен там, где вид заголовка требуется, а его смысл — нет:

html
<div class="prose--exdoc">
  <h1>Название статьи</h1>

  <!-- Выглядит как h2, но заголовком раздела не является -->
  <p class="h2">Цена по запросу</p>

  <!-- Подпись в карточке -->
  <span class="h4">Доставка</span>
</div>

Так структура документа остаётся честной: поисковые системы и программы чтения с экрана видят один <h1> и настоящую иерархию разделов, а не шесть заголовков там, где просто нужен крупный текст.

Что важно знать:

  • Класс работает внутри области прозы — как и всё остальное. Чтобы он действовал и снаружи, включите заголовки вне текста: классы выходят наружу вместе с тегами, а в карточках они нужны чаще, чем в статьях.
  • На чужом заголовке класс не выигрывает: у <h3 class="h1"> сработают правила h3. Класс рассчитан на не-заголовочные теги.
  • Если тема объявляет собственные .h1–.h6, вес правил окажется одинаковым, и результат решит порядок подключения стилей: подключайте стиль exDoc после стилей темы.

Цитата как врезка ​

Цитату можно оформить не подчёркнутым абзацем, а отдельным объектом на странице: рамка слева, скругление, своя ширина, декоративная кавычка и подпись автора.

html
<div class="prose--exdoc">
  <blockquote>
    Хорошая цитата не нуждается в украшениях — но врезка помогает читателю
    не пропустить её при беглом просмотре.
    <footer>Иван Фёдоров</footer>
  </blockquote>
</div>

Что важно знать:

  • Скругление правится по углам. У врезки с линией слева оно почти всегда несимметричное — например, скруглены только правые углы. Свёрнутый вид задаёт одно значение на все четыре угла, развёрнутый — каждый угол отдельно.
  • Ширина врезки ограничивается своим полем, а центрируется внешними отступами: значение 2rem auto вводится в них как обычное.
  • Декоративная кавычка выключена по умолчанию. Символ можно задать любой; поля позиции у неё нет — знак садится во внутренний угол врезки, и двигают его отступами самой цитаты. Кликам и выделению текста он не мешает.
  • Подпись автора — тег <footer> внутри цитаты. Отдельного включения ей не нужно: пока поля пусты, никаких правил не появляется. Тумблер «прямое начертание» снимает с подписи курсив, унаследованный от врезки.
  • Размер знака и все поля подписи работают по слоям брейкпоинтов: крупную кавычку на узком экране обычно уменьшают.
  • Ссылка внутри цитаты своих настроек не имеет — она берёт их из раздела ссылок.

Курсив цитаты изменился

Раньше выключенный тумблер «Курсив» не выводил ничего, и курсив, назначенный цитате темой, отменить было нечем. Теперь начертание выводится в обоих положениях: включённый тумблер даёт курсив, выключенный — прямое начертание.

Если у вас цитаты были курсивными из-за стилей темы, а тумблер выключен — после обновления курсив пропадёт. Вернуть его — включить тумблер.

Адаптив: слои брейкпоинтов ​

Значения задаются слоями. Базовый слой действует на всех экранах, слой брейкпоинта — начиная со своей ширины и шире (правило «сначала мобильные»).

Например: базовый h1 — 32px, на слое ≥992px — 56px. На узких экранах заголовок останется 32px, на широких станет 56px, а промежуточные значения задавать не нужно — их не будет.

Пустое поле на слое означает «наследовать»: значение придёт с ближайшего более узкого слоя. В подсказке поля видно, что действует сейчас.

Брейкпоинты — общие для всего проекта, они настраиваются на своей вкладке переменных. Слой появляется автоматически для каждого из них.

Плавный размер ​

Альтернатива слоям для размеров: вместо ступенек задаётся пара «от / до», и размер меняется плавно вместе с шириной экрана. Границы диапазона — самый узкий и самый широкий брейкпоинт проекта.

Плавный режим один на всю лестницу заголовков: способ задания размера — общее решение, а не отдельное для каждого уровня.

CSS-переменные размеров ​

Размеры эмитятся переменными на контейнере — их можно переиспользовать в своих стилях. При включённых заголовках вне текста размеры лестницы объявляются на :root и доступны в любом месте страницы:

css
--ex-prose-fs-base   /* базовый размер текста */
--ex-prose-fs-h1     /* … и по одной на каждый уровень */
--ex-prose-fs-h6

Так, например, подпись в карточке можно связать с размером h4, не дублируя число:

css
.card__caption {
  font-size: var(--ex-prose-fs-h4);
}

Тёмная тема ​

Цвета по умолчанию берутся из ролей цветовой схемы, а не задаются числом. Поэтому текст и ссылки переворачиваются вместе с тёмным вариантом схемы сами — отдельных настроек для тёмной темы у типографики нет.

Если вы поставите свой цвет вручную, он останется одинаковым в обеих темах — это осознанный выбор, но проверьте контраст. В превью конструктора рядом с текстом показан коэффициент контраста и отметка соответствия WCAG.
